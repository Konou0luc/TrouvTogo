# Prompt Trae — TrouvTogo Frontend Next.js (API v1.0 — Specs officielles)

---

## Contexte du projet

Tu vas créer le **frontend web complet** de **TrouvTogo** — une plateforme de signalement et récupération d'objets perdus au **Togo** (Afrique de l'Ouest). Projet réel, production. Interface **professionnelle, moderne, responsive, soignée**.

TrouvTogo permet à tout citoyen togolais de :
- Signaler un objet **perdu** ou **trouvé**
- Recevoir des **suggestions de matching automatique** (algorithme de scoring 0–100)
- **Contacter** la personne concernée via messagerie interne anonymisée
- Recevoir des **notifications** en temps réel (in-app, SMS, WhatsApp)

**Backend** : API REST — base URL `https://api.trouvtogo.com/v1` (dev : `http://localhost:3000/v1`)
**Auth** : JWT Bearer token (`Authorization: Bearer <token>`) + refresh token
**Déploiement** : Vercel (frontend) · Railway (backend + PostgreSQL) · Cloudinary (images)

### Convention couleurs sémantiques
- **LOST** (perdu) → `danger` (rouge) — badge rouge, marqueur rouge sur carte
- **FOUND** (trouvé) → `secondary` (vert) — badge vert, marqueur vert sur carte
- **Match score ≥ 70** → `secondary` — bonne correspondance
- **Match score 40–69** → `accent` — correspondance moyenne
- **Match score < 40** → `neutral` — faible correspondance

### Règles UI strictes
- Arrondis : `rounded-xl` cartes, `rounded-full` pills/badges, `rounded-lg` boutons
- Ombres : `shadow-sm` repos, `shadow-md` hover — jamais plus
- Bordures : `border border-neutral-200` (0.5px en SVG, `1px` en CSS)
- Transitions : `transition-all duration-200` sur tout élément interactif
- Skeleton loaders sur **toutes** les listes et requêtes
- États **loading / empty / error** obligatoires sur chaque composant de liste

## Client API — implémentation complète

```typescript
// lib/api.ts
import axios from 'axios'

const BASE_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:3000/v1'

export const api = axios.create({ baseURL: BASE_URL })

// Injecter le token JWT automatiquement
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// Refresh token si 401
api.interceptors.response.use(
  (res) => res,
  async (error) => {
    if (error.response?.status === 401) {
      const refreshToken = localStorage.getItem('refreshToken')
      if (refreshToken) {
        try {
          const { data } = await axios.post(`${BASE_URL}/auth/refresh`, { refreshToken })
          localStorage.setItem('token', data.token)
          error.config.headers.Authorization = `Bearer ${data.token}`
          return api(error.config)
        } catch {
          localStorage.removeItem('token')
          localStorage.removeItem('refreshToken')
          window.location.href = '/login'
        }
      }
    }
    return Promise.reject(error)
  }
)

// ── Auth ──────────────────────────────────────────────────────────
export const authAPI = {
  register:       (data: RegisterRequest)        => api.post<AuthResponse>('/auth/register', data),
  login:          (data: LoginRequest)           => api.post<AuthResponse>('/auth/login', data),
  logout:         ()                             => api.post('/auth/logout'),
  refresh:        (refreshToken: string)         => api.post('/auth/refresh', { refreshToken }),
  forgotPassword: (email: string)                => api.post('/auth/forgot-password', { email }),
  resetPassword:  (token: string, newPassword: string) =>
                    api.post('/auth/reset-password', { token, newPassword }),
}

// ── Users ─────────────────────────────────────────────────────────
export const usersAPI = {
  getMe:      ()                => api.get<User>('/users/me'),
  updateMe:   (data: Partial<User>) => api.put<User>('/users/me', data),
  getMyStats: ()                => api.get<UserStats>('/users/me/stats'),
  getUser:    (id: number)      => api.get<UserPublic>(`/users/${id}`),
}

// ── Items ─────────────────────────────────────────────────────────
export const itemsAPI = {
  list:      (params?: Partial<SearchRequest>) => api.get<SearchResponse>('/items', { params }),
  get:       (id: number)                      => api.get<Item>(`/items/${id}`),
  create:    (data: FormData)                  => api.post<Item>('/items', data, {
               headers: { 'Content-Type': 'multipart/form-data' } }),
  update:    (id: number, data: Partial<CreateItemRequest>) => api.put<Item>(`/items/${id}`, data),
  delete:    (id: number)                      => api.delete(`/items/${id}`),
  resolve:   (id: number, message?: string)    => api.patch<Item>(`/items/${id}/resolve`, { message }),
  getMyItems:(params?: { status?: ItemStatus; type?: ItemType }) =>
               api.get<Item[]>('/items/user/me', { params }),
}

// ── Matching ──────────────────────────────────────────────────────
export const matchingAPI = {
  forItem: (itemId: number, params?: { minScore?: number; limit?: number }) =>
             api.get<{ sourceItem: Item; matches: MatchResult[]; total: number }>(
               `/matches/for-item/${itemId}`, { params }),

  suggestions: (params?: { limit?: number; minScore?: number; onlyUnread?: boolean }) =>
                 api.get<SuggestionsResponse>('/matches/suggestions', { params }),

  newMatches: (params?: { since?: string; minScore?: number }) =>
                api.get<{ matches: MatchResult[]; total: number; since: string }>(
                  '/matches/new', { params }),

  trigger:    (itemId: number) => api.post(`/matches/trigger/${itemId}`),
  triggerAll: ()               => api.post('/matches/trigger-all'),

  getScore:   (matchId: number) => api.get(`/matches/${matchId}/score`),
  markRead:   (matchId: number) => api.patch(`/matches/${matchId}/read`),

  unreadCount: () => api.get<{ count: number; highScoreCount: number }>('/matches/unread-count'),
}

// ── Search ────────────────────────────────────────────────────────
export const searchAPI = {
  search: (data: SearchRequest)            => api.post<SearchResponse>('/search', data),
  nearby: (lat: number, lng: number, params?: { radius?: number; type?: ItemType; limit?: number }) =>
            api.get<Item[]>('/search/nearby', { params: { latitude: lat, longitude: lng, ...params } }),
}

// ── Conversations & Messages ──────────────────────────────────────
export const messagesAPI = {
  getConversations:  (params?: { page?: number; limit?: number }) =>
                       api.get<Conversation[]>('/conversations', { params }),
  createConversation:(data: { itemId: number; matchId?: number }) =>

  getMessages:       (convId: number, params?: { page?: number; limit?: number }) =>
                       api.get<Message[]>(`/conversations/${convId}/messages`, { params }),
  sendMessage:       (convId: number, content: string) =>

  markAllRead:()            => api.patch('/notifications/read-all'),
  unreadCount:()            => api.get<{ count: number; byType: Record<string, number> }>(
                                '/notifications/unread-count'),
}

// ── Stats ─────────────────────────────────────────────────────────
```

## Store Zustand

```typescript
// store/useAppStore.ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

interface AppStore {
  user: User | null
  token: string | null
  refreshToken: string | null
  unreadNotifications: number
  unreadMatches: number
  unreadMessages: number

  setAuth: (user: User, token: string, refreshToken: string) => void
  clearAuth: () => void
  setUnreadCounts: (notifs: number, matches: number, messages: number) => void
}

export const useAppStore = create<AppStore>()(
  persist(
    (set) => ({
      user: null, token: null, refreshToken: null,
      unreadNotifications: 0, unreadMatches: 0, unreadMessages: 0,

      setAuth: (user, token, refreshToken) => {
        localStorage.setItem('token', token)
        localStorage.setItem('refreshToken', refreshToken)
        set({ user, token, refreshToken })
      },
      clearAuth: () => {
        localStorage.removeItem('token')
        localStorage.removeItem('refreshToken')
        set({ user: null, token: null, refreshToken: null })
      },
      setUnreadCounts: (unreadNotifications, unreadMatches, unreadMessages) =>
        set({ unreadNotifications, unreadMatches, unreadMessages }),
    }),
    { name: 'trouvtogo-store', partialize: (s) => ({ user: s.user, token: s.token, refreshToken: s.refreshToken }) }
  )
)
```

## Pages — description précise

### 1. `/` — Accueil

**Hero :**
- Titre : "Retrouvez vos objets perdus au Togo"
- Sous-titre sobre
- 2 CTA côte à côte : "J'ai perdu un objet" (primary) · "J'ai trouvé un objet" (secondary)

**Stats publiques** — appel `GET /stats/public` :
- 3 cards animées (compteur au scroll) : `totalItems`, `resolvedItems`, `activeUsers`
- `successRate` affiché en pourcentage avec anneau SVG

**Comment ça marche :** 3 étapes illustrées (Signalez → Matching → Récupérez)

**Dernières annonces** — appel `GET /items?limit=6&sortBy=RECENT` :
- Grille 3 cols desktop / 2 tablet / 1 mobile
- Skeleton lors du chargement

---

### 2. `/annonces` — Fil + carte GPS

**Layout split :**
- Gauche (40%) : liste filtrée avec recherche et filtres
- Droite (60%) : carte Leaflet (import dynamique obligatoire)

**Filtres :**
- Pills : Tous / Perdus (`type=LOST`) / Trouvés (`type=FOUND`)
- Dropdown catégorie : `ELECTRONICS, IDENTITY_PAPERS, KEYS, LUGGAGE, CLOTHING, WALLET, PHONE, JEWELRY, BOOKS, PETS, OTHER`
- Dropdown ville : Lomé, Kpalimé, Sokodé, Atakpamé, Kara, Dapaong
- Tri : `RECENT, RELEVANCE, DISTANCE, MATCH_SCORE`
- Recherche texte → `POST /search`

**Appels API :**
```
GET /items?type=&category=&city=&page=&limit=20
POST /search (recherche avancée)
GET /search/nearby?latitude=&longitude=&radius=10 (bouton "Près de moi")
```

**Carte Leaflet :**
- Centré Lomé `{ lat: 6.1375, lng: 1.2123 }` zoom 13
- Marqueurs custom : rouge SVG pour LOST, vert SVG pour FOUND
- Clustering automatique (react-leaflet-cluster)
- Popup au clic : titre + badge + bouton "Voir le détail"
- Bouton géolocalisation → `GET /search/nearby`
- Sur mobile : tabs "Liste" / "Carte"

---

### 3. `/annonces/[id]` — Détail annonce

**Appels API :**
```
GET /items/{id}                                        # Données annonce
GET /matches/for-item/{id}?minScore=40&limit=5        # Matches liés (si connecté)
GET /items?category={cat}&city={city}&limit=3          # Annonces similaires
```

**Contenu :**
- Galerie photos (ou placeholder)
- Badge `LOST`/`FOUND` coloré + badge `status`
- Badge récompense si `reward !== null`
- Titre, catégorie, description complète
- Location : adresse, district, ville
- Mini-carte Leaflet non-interactive (point fixe)
- Date de perte/découverte + lieu de dépôt si FOUND

**Bannière match** (si `matches.length > 0`, connecté) :
- Fond `secondary.light`, texte : "X correspondance(s) trouvée(s)"
- Score du meilleur match avec barre colorée
- CTA "Voir les correspondances"

**Actions :**
- "Contacter" → `POST /conversations` avec `{ itemId, matchId }` → ouvre dialog messagerie
- "Partager sur WhatsApp" → `https://wa.me/?text=...`
- Si propriétaire → "Marquer comme résolu" → `PATCH /items/{id}/resolve`
- "Signaler un abus" (lien discret)

### 4. `/declarer/perdu` et `/declarer/trouve`

**Stepper 4 étapes avec barre de progression :**

**Étape 1 — Catégorie :**
- Grille cards cliquables avec icônes Lucide :
  - `PHONE` → Smartphone
  - `IDENTITY_PAPERS` → CreditCard
  - `KEYS` → Key
  - `LUGGAGE` → Briefcase
  - `WALLET` → Wallet
  - `ELECTRONICS` → Laptop
  - `JEWELRY` → Gem
  - `CLOTHING` → Shirt
  - `PETS` → PawPrint
  - `BOOKS` → BookOpen
  - `OTHER` → Package
- Card sélectionnée → bordure primary + fond primary.light + checkmark

**Étape 2 — Description :**
- Champ `title` (obligatoire)
- Textarea `description` (obligatoire, max 2000 chars, compteur de caractères)
- Champ `reward` (optionnel) — "Récompense offerte (ex: 5000 FCFA)"
- Upload `images` : drag & drop + clic, prévisualisation, max 5 photos
- Si FOUND : avertissement "Ne mentionnez pas les infos sensibles (nom complet, numéro…)"

**Étape 3 — Lieu & date :**
- Champ `location.district` avec suggestions (autocomplete) :
  Adidogomé, Bè, Agoè, Tokoin, Nyékonakpoè, Kodjoviakopé, Hédzranawoé, Aflao, Djidjolé…

## Règles de qualité — non négociables

1. **TypeScript strict** : zéro `any`, tous les props et retours typés
2. **SSR-safe** : import dynamique `{ ssr: false }` pour Leaflet, sans exception
3. **États UI complets** : loading (skeleton) · empty (illustration + texte) · error (message + retry)
4. **Accessibilité** : `aria-label` sur boutons icon-only, contraste WCAG AA
5. **Performance** : `next/image` pour toutes les images, pagination infinie ou "Voir plus"
6. **SEO** : `generateMetadata` sur chaque page publique
7. **Responsive strict** : mobile-first, testé à 375px, 768px, 1280px
8. **Conventions** : composants < 200 lignes, logique dans les hooks, pages = composition uniquement
